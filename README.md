
# 🇬🇧 Tableau-UK-Employment-Data
### *A Tableau project analyzing employment trends across industries and cities in the United Kingdom*

## 📌 Overview  
This Tableau dashboard explores employment trends in the United Kingdom through multiple dimensions, including industries, sub-industries, and geographic regions.  
The goal of this project is to highlight changes in employment levels and provide a clear understanding of how economic sectors and cities evolve over time.

---
